# miau-mir4-releases
# MIAU MIR4

Aplicación de escritorio para Windows para organizar personajes, actividades semanales, horarios y encargos de MIR4. Guarda los datos en el equipo y funciona sin conexión.

## Descargar

Abrí **Releases** en este repositorio y descargá el ZIP portable de la versión más reciente. Extraelo completo en una carpeta y abrí **MIAU MIR4.exe**. El ZIP incluye un tarifario inicial y una base vacía para que puedas cargar tus propios personajes.

## Actualizar el portable

1. Cerrá la app anterior y guardá una copia de seguridad de su carpeta `datos`.
2. Extraé el ZIP nuevo en una carpeta distinta.
3. Antes de abrir la versión nueva, reemplazá su carpeta `datos` por una copia completa de la carpeta `datos` anterior.
4. Abrí **MIAU MIR4.exe** desde la carpeta nueva y comprobá que estén tus personajes.

La carpeta `datos` conserva personajes, progreso, encargos, pagos y tarifas. Guardá la carpeta anterior como respaldo.

## Versiones

La versión 0.9.17 incluye las invocaciones Valle Dominacion 1F, 2F y 3F con sus recetas. En Hoy y Calendario, los jefes de mapa y Red Boss de Cima muestran su hora de aparición.

Las actualizaciones de esta versión portable se instalan descargando el ZIP desde **Releases**.
